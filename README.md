# Сюжетник

Мобильный помощник сценариста: библия проекта с персонажами, локациями, картой связей и экспозицией.

У каждого проекта свой **шаблон мира**:
- киберпанк — фракция, корп/банда, импланты;
- фэнтези — класс, раса, орден;
- нуар — принадлежность, тайна;
- пустой — только базовые поля.

## Запуск в браузере

```bash
npm install
npm run dev
```

Откройте http://127.0.0.1:43127

Демо уже внутри: «Ночной трамвай» (нуар) и «Неоновый долг» (киберпанк).

## Что умеет

- несколько независимых проектов (разные миры — разные поля);
- карточки персонажей и локаций по шаблону жанра;
- **граф связей** (тянуть узлы, соединять линиями);
- **матрица давления** — все пары персонажей с учётом типа связи, доверия, напряжения и совпадений/разломов по полям шаблона;
- заметки экспозиции;
- локальное хранение (без аккаунта).

## Android APK (debug)

```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```

Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`

Установка: скопируйте APK на телефон и разрешите установку из неизвестных источников.

## Стек

Next.js (static export) + Capacitor + React Flow. Данные в `localStorage`.
