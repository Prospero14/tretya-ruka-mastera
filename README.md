# Сюжетник

Помощник мастера для **настольных ролёвок** и рассказов за столом: кампании, one-shot, модули.

Не географическая карта — вкладка **Связи** это схема отношений PC/NPC (долги, тайны, фракции).

## Запуск

```bash
npm install
npm run dev
```

http://127.0.0.1:43127

Демо: «Ночной трамвай» (городской нуар) и «Неоновый долг» (киберпанк).

## Возможности

- проекты-кампании со своим шаблоном мира (фэнтези / киберпанк / нуар / свой);
- свои поля у PC/NPC и локаций;
- синопсис на вкладке **Обзор**;
- схема и матрица **связей** (без тяжёлого React Flow);
- поиск рефов в Google Images;
- напоминания о дырах в подготовке (до 2 раз в день);
- локальное хранение.
