# Сюжетник

Мобильный помощник сценариста: библия проекта с персонажами, локациями, картой взаимодействий и экспозицией.

Первый срез — progressive web app (удобно на Android в Chrome: «Добавить на главный экран»). Данные хранятся локально в браузере.

## Запуск

```bash
npm install
npm run dev -- --port 43127 --hostname 127.0.0.1
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Что уже есть

- проекты сценария (демо «Ночной трамвай»)
- карточки персонажей: роль, цель, изъян, экспозиция
- локации с настроением и функцией в истории
- интерактивная карта связей (тянуть узлы, соединять линиями)
- заметки экспозиции с тегами
