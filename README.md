# Третья рука мастера

Запиши свои сюжетные повороты — пока они ещё горячие.

Помощник для настольных ролёвок: кампании, PC/NPC, локации, связи, синопсис.

## Запуск

```bash
npm install
npm run dev
```

http://127.0.0.1:43127

## Android APK

```bash
npm run apk:debug
```

Файл: `android/app/build/outputs/apk/debug/app-debug.apk`
